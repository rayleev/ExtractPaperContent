## 特别说明：本论文为管理/栽培措施型试验（management_yield）

{variety_constraint}

本论文研究的是**栽培管理措施**（如施肥量、灌溉方式、播期、密度、耕作方式、肥料种类等）
对产量的影响。这类论文的数据表格中，每一行通常是**不同的处理水平**
（例如施氮量 N0/N1/N2/N3、不同灌溉处理、不同密度梯度），而**不是不同品种**；
试验通常只使用 1-2 个固定品种。

## 提取要求（重要变更：提取全部处理水平）

**提取该试验中全部处理水平的数据，每个处理一行**，包括对照组和各处理水平
（如 N0/N1/N2/N3、常规灌溉/滴灌/亏缺灌溉、低密度/中密度/高密度等）。

- `variety_name` 填写该试验**固定使用的品种名称**（如 "郑单958"、"川优6203"），
  **不要**填写处理名称（如 "N180"、"滴灌"、"高密度"）
- 如果试验包含多个品种、且每个品种都设有多个处理水平，则**每个品种 × 每个处理水平各提取一行**
- 对照处理（如 CK、N0、常规栽培、不施肥）对应的记录 `is_check_variety` 设为 `true`
- 其他处理水平（如 N180、滴灌、高密度）对应的记录 `is_check_variety` 设为 `false`
- 在 `source_location` 中标注该处理在表格中的位置（如 "表3-N0行"、"表3-N180行"）
- 其余栽培管理信息可填入 `cultural_practices` / `experimental_design_description`

## treatment_name 字段（处理名称，本类别必填）

本类别下 `treatment_name` 用于记录该行的**处理水平名称**：

- 肥料试验：填施氮/磷/钾水平，如 `"N0"`、`"N180"`、`"N240"`、`"N0P0K0"`、`"N180P90K120"`
- 灌溉试验：填灌溉处理，如 `"常规灌溉"`、`"滴灌"`、`"亏缺灌溉"`、`"W1"`、`"W2"`
- 密度试验：填密度处理，如 `"低密度"`、`"中密度"`、`"高密度"`、`"D1"`、`"D2"`
- 其他管理：填具体处理名，如 `"覆膜"`、`"不覆膜"`、`"秸秆还田"`、`"常规耕作"`
- 对照处理：填 `"CK"` 或 `"N0"` 或 `"常规栽培"` 等论文中对照处理的原始名称

## 氮磷钾(NPK)施用量提取规则（重要）

对于**肥料试验**的处理，提取该处理的氮磷钾施用量：

1. **只抄录论文中明确写出的纯养分量**：
   - 论文写"施纯氮 180 kg/ha" → n_raw_value=180, n_raw_unit="kg/ha"
   - 论文写"施 P2O5 90 kg/ha" → p_raw_value=90, p_raw_unit="kg/ha"
   - 论文写"施 K2O 120 kg/hm²" → k_raw_value=120, k_raw_unit="kg/hm²"

2. **复合肥/有机肥处理**：
   - 若论文明确标注 N-P-K%（如"15-15-15 复合肥 600 kg/ha"），按标注折算纯养分量填入
   - 若论文只给总量（如"施复合肥 750 kg/ha"）**未给养分含量**，则 n/p/k_raw_value 一律填 null
   - 有机肥若论文未给 N-P-K 含量，n/p/k_raw_value 填 null

3. **对照处理（N0/不施肥）**：
   - 论文明确写"不施氮"或"N0" → n_raw_value=0, n_raw_unit 填论文中其他处理使用的单位（保持单位一致）
   - 若论文未明确写对照的养分量，按"不施肥"推断 N/P/K 均为 0

4. **单位**：
   - n_raw_unit/p_raw_unit/k_raw_unit 填论文原始单位（如 'kg/ha'、'kg/hm²'、'kg/亩'），**不要换算**
   - 不要填 n_standard_value/p_standard_value/k_standard_value，这三个字段由程序自动换算

5. **非肥料处理（灌溉/密度/耕作等）**：
   - NPK 字段（n/p/k_raw_value + n/p/k_raw_unit）**全部填 null**
   - treatment_name 仍填处理名（如 "滴灌"、"高密度"）
   - 这些处理的 NPK 信息由 `cultural_practices` 或 `experimental_design_description` 自由文本承载

6. **NPK 数据来源标注**（重要）：
   - 当填入了 n/p/k_raw_value 时，必须在 `nutrient_source_location` 字段中标注这些数据的来源位置
   - 例如："表2"、"表3-N180行"、"材料方法-试验设计"、"表1 施肥方案"
   - 如果 NPK 全部为 null（非肥料处理），`nutrient_source_location` 也填 null

## is_check_variety 字段的双语义

`is_check_variety` 在不同论文类别中有**不同含义**，请正确理解：

| 论文类别 | is_check_variety = true 的含义 |
|----------|-------------------------------|
| **varietal_yield**（品种比较型） | 该品种是**对照品种**（CK），即试验中作为对照的品种 |
| **management_yield**（管理措施型） | 该记录是**对照处理**（CK），即常规栽培/不施肥/基准处理等 |

**本论文为 management_yield，因此：**
- `is_check_variety = true` → 表示该记录是**对照处理**（如常规栽培、不施肥 N0、当地常用措施等）
- `is_check_variety = false` → 表示该记录是**其他处理**（如高量施肥 N180、滴灌、高密度等）
- 如果论文中所有处理都是平等的（没有明确对照），则所有记录 `is_check_variety = false`
