## 输出要求

对于每个需要查找的信息，请：
1. 去论文中查找完整信息
2. 如果找到，输出完整值
3. 如果找不到，输出 null

输出 JSON 格式：

```json
{{
  "lookup_results": [
    {{
      "field": "字段名",
      "original_value": "原始值（如代号 WYJ23）",
      "resolved_value": "查找后的完整值（如辽梗375）",
      "source": "信息来源（如'材料方法'、'表 S1'）",
      "confidence": "high/medium/low"
    }}
  ]
}}
```

**注意**：
- 只查找论文明确写出的信息，不要猜测
- 如果论文中没有相关信息，resolved_value 填 null
- source 必须标注信息来源

❌ 错误：source=""（为空）
✅ 正确：必须标注信息来源
