你是一个专业的农业科研文献数据提取专家。请从以下试验章节中提取品种产量数据。

## 任务说明

这是**第二阶段提取**，针对论文中某个具体试验的品种产量数据提取。
请仔细分析该试验的结果和表格数据，提取所有品种产量信息。

## 提取规则（请严格遵守）

1. **只提取论文中明确存在的数据**，绝不编造或推测
2. **注意同义表述**：论文中的表述可能与字段名不同但含义一致
   - "小区面积"="plot_size"，"重复次数"="replication_number"
   - "播种期"/"播种日期"="sowing_date"，"收获期"/"收获日期"="harvest_date"
   - "试验地"/"试验地点"="experimental_site_name"
   - "对照"/"CK"/"check"=is_check_variety=true
   - "增产率"/"增幅"/"比CK增产"=pct_over_check
   - "显著性标记"/"Duncan检验字母"/"多重比较字母"=significance_group
3. **模糊日期处理规则**（适用于 sowing_date 和 harvest_date）：
   - 如果论文写"5月27日播种"→ sowing_date="2022-05-27"（年份从 trial_year 取）
   - 如果论文写"10月收获"→ harvest_date="2022-10"（只精确到月）
   - 如果论文写"10月15日收获"→ harvest_date="2022-10-15"
   - 如果论文写"9月下旬至10月上旬收获"→ harvest_date="2022-09"（取起始月）
   - 如果论文写"全生育期 120 天"且有 sowing_date→ harvest_date 从 sowing_date + 120 天推算
   - 如果论文没有写收获日期→ harvest_date 填 null
4. **产量只提取原始值和单位，不要换算**
   - 只提取 yield_raw_value（原始数值）和 yield_raw_unit（原始单位）
   - 不要填写 yield_standard_value 和 yield_standard_unit，这两个字段由程序自动换算
   - 例如论文写"亩产445.3kg"，则 yield_raw_value=445.3, yield_raw_unit="kg/亩"
5. **经纬度和海拔**：仅当论文中**明确写出具体数值**时才提取（如"试验站位于北纬30.5°、东经114.3°、海拔25m"），否则填 null
6. **缺失字段填 null**，不要猜测
7. **每个品种一条记录**：从表格或文字中提取每个品种的产量数据
8. **氮磷钾(NPK)施用量提取规则**（重要）：
   - 只抄录论文中**明确写出的纯养分量**（如"施纯氮 180 kg/ha"、"施 P2O5 90 kg/ha"、"施 K2O 120 kg/ha"）
   - 复合肥/有机肥若论文只给总量（如"施复合肥 750 kg/ha"）而**未给养分含量**，则 n/p/k_raw_value 一律填 null
   - 复合肥若论文明确标注 N-P-K%（如"15-15-15 复合肥 600 kg/ha"），可分别折算纯养分量填入
   - n_raw_unit/p_raw_unit/k_raw_unit 填论文原始单位（如 'kg/ha'、'kg/hm²'、'kg/亩'），不要换算
   - 不要填 n_standard_value/p_standard_value/k_standard_value，这三个字段由程序自动换算
   - 品种比较试验（非肥料试验）NPK 字段全部填 null
   - 肥料试验中某处理若论文未提某种养分（如只施氮不施磷钾），则该养分 raw_value 填 0 或 null（按论文表述）

## 数据质量规则（必须遵守）

1. **对照品种**：每个试验必须有一个 is_check_variety=true 的品种
2. **品种名称**：必须是具体名称（如"辽梗375"），不能是代号（如"WYJ23"）或模糊描述（如"27份材料"）
3. **产量范围**：水稻产量通常在 500-18000 kg/ha 之间（如换算后超出此范围，标记 confidence=low）
4. **增产率**：pct_over_check 应该与对照品种计算一致（偏差 <1%）
5. **产量单位**：不能是 %（增产比例），如果是 % 则跳过该记录

## 输出JSON格式

严格输出以下JSON格式，不要包含任何其他文字：
```json
{{
  "varieties": [
    {{
      "variety_name": "[REQUIRED] 品种名称",
      "variety_code": "品种审定编号（如有）",
      "is_check_variety": "[REQUIRED] 是否为对照品种 true/false",
      "variety_source": "育种单位/来源",
      "yield_raw_value": "[REQUIRED] 原始产量数值",
      "yield_raw_unit": "[REQUIRED] 原始产量单位",
      "yield_value_type": "<plot_mean|single_replicate|converted>",
      "significance_group": "显著性字母标记",
      "pct_over_check": "增产/减产百分比",
      "measurement_method": "产量测定与计产方法",
      "source_location": "[REQUIRED] 数据来源位置，如 '表3'、'2.3节'",
      "confidence_level": "<high|medium|low>",
      "treatment_name": "[OPTIONAL] 处理名称，肥料/灌溉/密度试验填处理名(如 'N0'/'N180'/'CK')，品种比较试验填 null",
      "n_raw_value": "[OPTIONAL] 纯氮施用量数值，如 180",
      "n_raw_unit": "[OPTIONAL] 氮施用量原始单位，如 'kg/ha'",
      "p_raw_value": "[OPTIONAL] 纯磷(P2O5)施用量数值",
      "p_raw_unit": "[OPTIONAL] 磷施用量原始单位",
      "k_raw_value": "[OPTIONAL] 纯钾(K2O)施用量数值",
      "k_raw_unit": "[OPTIONAL] 钾施用量原始单位",
      "nutrient_source_location": "[OPTIONAL] 氮磷钾施用量数据的来源位置，如 '表2'、'表3-N180行'、'材料方法'"
    }}
  ]
}}
```

**注意**：
- varieties 数组包含该试验中**所有品种**的数据，不要遗漏
- 从表格中逐行提取每个品种的数据
- 对照品种（CK）也要包含在 varieties 中，is_check_variety 设为 true
- 如果表格中没有产量数据，但有其他农艺性状数据，也尽量提取品种信息
- yield_value_type: plot_mean=小区均值, single_replicate=单次重复, converted=从其他单位换算
- confidence_level: high=数据明确, medium=可能有细微偏差, low=数据不够明确
- source_location 必须标注数据来源（如 "表3"、"Table 5"、"3.2.3节"）
- experimental_design_type 只能用 RCBD / Split-plot / CRD / Unknown
- latitude/longitude/altitude 仅在论文明确写出时提取，否则填 null
- 不要填 yield_standard_value、yield_standard_unit、geo_source、n_standard_value、p_standard_value、k_standard_value

## 多作物处理

如果试验包含多种作物，请按作物拆分 variety：
- 每个 variety 必须是具体作物的品种
- 从试验内容中识别该作物的品种和产量数据

## 共用品种处理（重要）

如果 `study_context` 中包含"共用品种"信息，请遵守以下规则：
1. **共用品种**（标记为 [共用]）是多个试验共享的品种，特别是 CK（对照）
2. 提取 variety 时，如果该品种在共用品种列表中，**使用共用品种列表中的标准名称**
3. 不要为共用品种编造不同的名称
4. 共用品种的 `variety_name` 应该在所有试验中保持一致

**示例**：
- 共用品种列表：虾稻一号（CK）[共用]
- 表3-1 中写"CK" → variety_name = "虾稻一号"
- 表4-1 中写"CK" → variety_name = "虾稻一号"（不是"黄华占"）

## 常见错误示例

❌ 错误：variety_name="WYJ23"（代号）
✅ 正确：variety_name 必须是具体名称，代号需要去材料方法查找全称

❌ 错误：variety_name="27份中稻亲本材料"（模糊描述）
✅ 正确：variety_name 不能是模糊描述

❌ 错误：is_check_variety 全部为 false
✅ 正确：每个试验必须有一个对照品种（is_check_variety=true）

❌ 错误：yield_raw_unit="%"（增产比例）
✅ 正确：跳过该记录，% 不是实际产量单位

❌ 错误：source_location=""（为空）
✅ 正确：必须标注数据来源（如"表3"）

❌ 错误：pct_over_check=8.3，但对照品种产量 565.4，实际增产率 (612.5-565.4)/565.4*100=8.3%
✅ 正确：增产率应与对照品种计算一致
