## 验证要求

对每个字段：
1. 检查候选证据是否正确支持字段值
2. 如果候选证据正确，确认该证据
3. 如果候选证据错误或缺失，从论文中找到正确的证据
4. 给出具体的论文位置和原文片段

## 输出格式

```json
{{
  "evidence_nodes": [
    {{
      "field": "字段名",
      "value": "字段值",
      "level": "paper / study / variety",
      "study_index": "S_01 / S_02",
      "variety_index": "V_01 / V_02",
      "treatment_name": "处理名称（无则填 ''）",
      "source_location": "来源位置（如'摘要'、'表3'、'3.2.3节'）",
      "source_text": "原文片段（50-200字）",
      "confidence": "high/medium/low",
      "verified": true/false,
      "reason": "判断原因（如'候选证据正确'、'候选证据位置错误，已纠正'）"
    }}
  ]
}}
```

## 注意事项

- 只验证论文明确写出的信息，不要猜测
- source_text 必须是论文中的原文片段
- confidence 表示证据的可靠程度：high=直接引用，medium=推断，low=不确定
- verified 表示证据是否通过验证
- **level** 标识字段层级：`paper`（论文级）、`study`（试验级）、`variety`（品种级），必须与输入中的 level 一致
- **study_index / variety_index / treatment_name** 必须与输入中对应字段的值一致（即使为空字符串也要原样返回，不能改为 null）

## 常见错误示例

❌ 错误：source_text 是自己总结的，不是原文
✅ 正确：source_text 必须是论文中的原文片段

❌ 错误：source_location="论文"（太模糊）
✅ 正确：source_location="表3" 或 "材料方法"（具体位置）

❌ 错误：verified=true，但 source_text 与 value 不匹配
✅ 正确：verified 必须基于 source_text 与 value 的一致性

❌ 错误：paper 级字段的 variety_index 返回 null
✅ 正确：variety_index 必须与输入一致（空字符串就返回空字符串 ""）

❌ 错误：treatment_name 返回 null
✅ 正确：treatment_name 无值时必须返回空字符串 ""，不能返回 null
